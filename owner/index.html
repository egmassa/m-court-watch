オーナー操作 Ver 3.4

巡回の状態

読み込み中…
無料プランで今月LINEを送れる残りの通数です。全員送信は友だち1人につき1通と数えるので、1回の通知で友だちの人数分減ります。毎月1日に200通に戻ります。

操作

ボタンを使うには、下でアクセストークンを登録してください。
今すぐチェック：すぐに巡回します。前回から新しく見つかった空きだけを、LINEで通知します。新しい空きがなければ、LINEは送りません。
全部LINEで再送：記録を空にしてから巡回し、今空いている枠をすべてLINEで通知します。すでに通知した空きも、もう一度送ります。友だち全員に送るので、1回で人数分のLINE通数を使います。空きが多いときは、要約だけを送ります。
どちらも：「監視の条件」で決めた内容で巡回します。結果が空き一覧に出るまで、1分ほどかかります。ふだんは、日本時間の6時〜24時に、30分おきに自動で巡回しています。
アクセストークン

「今すぐチェック」と「全部LINEで再送」に使います。このブラウザの中にだけ保存されます。

  1. GitHub 右上のアイコン →「Settings」→ 左下「Developer settings」
  2. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
  3. Expiration: 1年など / Repository access: Only select repositories →
  4. Permissions → Repository permissions で
    Contents と Actions を「Read and write」
  5. 「Generate token」→ 表示された github_pat_… をコピーして下に貼り付け
空き一覧を見る ／ 監視の条件を変える

GAS（Google Apps Script）
設定 →「スクリプト プロパティ」に次の名前があります。VIEW_HASHES（閲覧の合言葉）、EDIT_HASHES（友達の編集用）、OWNER_HASH（オーナーの合言葉。上限を変える用）、WRITE_TOKEN（巡回の鍵）、FILE_ID（状態ファイル）、COND_FILE_ID（条件ファイル。消すと config.yml の値に戻ります）。合言葉は、ハッシュだけを入れます。

GitHub の Secrets（リポジトリの Settings → Secrets and variables → Actions）
GAS_URL、GAS_WRITE_TOKEN、LINE_TOKEN、LINE_USER_ID

アクセストークン
アカウントの Settings → Developer settings → Fine-grained tokens。値は作ったときしか見られません。

GASの定期巡回：別のGASプロジェクトです。消さないでください。
